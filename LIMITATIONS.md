# Limitations — Verita
The honest scope boundary. Every gated item names its reason. A judge reads a deliberate boundary here, not a hidden gap. Honesty is placed secondary (not hero hedge-copy).

## In scope (built for this submission)
- The staked/slashable primitive `Verita.sol`: stake, attest, `safePrice` (reverts on unsafe + per-read USDG fee), `isTradeable`, `challenge` → slash.
- The reference consumer `LiquidationGuard.sol`: real wTSLAx collateral, USDG debt, mark-via-Verita, wrongful-liquidation refusal.
- Stale + halted + price-divergence reverts, and an organic-divergence slash driven by an independent signed report, live on X Layer 196.
- Real USDG movement on 196: a per-read fee and a slash to the harmed borrower.
- A judge-facing console (home + `/proof`) with a keys-off-host kill-shot.

## Feature-gated (deliberately not built for this scope)
- **Auto-detection of real corporate actions / splits.** Reason: scope + honesty — the wrapped token is Backed-controlled; splits/halts are honestly operator-tagged via the `MarketStatus` enum. Faking auto-detection would be dishonest.
- **A full lending protocol (auctions, interest, multi-collateral).** Reason: scope + anti-collision — the consumer is a THIN reference proving the primitive, not a market competing with agama (drift tripwire #3).
- **Multi-asset coverage beyond 2-3 xStocks.** Reason: time — one asset (wTSLAx) proves the loop; wNVDAx/wSPYx are optional stretch.
- **On-chain Chainlink Data Streams verification.** Reason: it is confirmed DEAD on 196 (`verify()` → `VerifierNotFound`). We replace it, we do not depend on it.
- **Protection/fills during a hard halt.** Reason: honest design — Verita REFUSES on bad status; it does not promise a fill into a frozen book (the PegGuard dead-book trap).

## Known honest caveats (disclosed, placed secondary)
- **The live mainnet proof settles in WOKB, not USDG.** Reason: USDG (`0x4ae4…2dc8`) is dormant on X Layer — verified on-chain, zero Transfer events over 30k+ blocks, no public DEX pool — and the OKX aggregator swap API is trial-plan-gated, so USDG cannot be acquired programmatically in small size. USDG remains the **designed-for** settlement token: it is the contract default, the token in all 14 unit tests, and the token in the fork consumer demo. The live organic-divergence slash on public 196 settles in **WOKB** (wrapped native OKB, `0xe538…9b2b`) because the slash path moves only the staked settlement token — the mechanism is identical. Verita's settlement token is a constructor parameter; nothing about the primitive changes. Disclosed; the headline is "real on-chain value moves on public 196," recomputable via `scripts/verify-claims.sh`.
- **The consumer's live collateral position is demonstrated on a fork of X Layer 196, not on public mainnet.** Reason: wTSLAx (`0xc3Fd…1171`, "Wrapped Tesla xStock") is a mint-on-deposit, issuer-KYC'd wrapper with **no retail DEX liquidity** on X Layer (verified on-chain: zero Transfer events over 50k+ blocks; owner holds 0 of ~1014 supply; supply grows only via issuer minting). It cannot be swap-acquired in small size. So the borrow → halt → **wrongful-liquidation refusal** (F-008) is proven by the green test suite AND on a mainnet-fork that deals dust wTSLAx to the borrower (real forked state, not a mock). **The primitive's HERO — the organic-divergence slash moving real USDG (F-005) — is proven on PUBLIC mainnet 196**, because the slash path moves only staked USDG and needs no wTSLAx. This split is deliberate and disclosed; nothing is presented as mainnet that ran on a fork.
- **Session/split status is operator-tagged in this build**, not auto-derived. The only ORGANICALLY-slashable trigger at demo scale is two-stream price divergence (plus a verifiable public halt). This is by design and disclosed; the "un-feedable" claim is scoped precisely to halt/split/de-peg accountability.
- **The kill-shot fetches and signs live at click-time (no replay).** `web/app/api/killshot/route.ts` fetches the live independent price when the button is pressed (Source B Finnhub → Yahoo v8 fallback), signs a FRESH EIP-712 report with the authorized reporter key, then challenges; it does not replay a pre-signed report. If neither price stream is reachable at that instant it **fails closed** (HTTP 502, "no live price") rather than fabricating a mark or falling back to a canned report. `challenge()` independently re-checks authorization + real on-chain divergence, so an honest mark reverts `NoDivergence` — the slash cannot be staged. (The relayer's separate `index.ts` batch path documents an unimplemented pre-seeded fallback that is a no-op and MUST never carry a canned price — F-013 sentinel.)
- **External (non-team) usage.** If no non-team reader has used Verita by submission, this is stated plainly here; it is never implied or faked. The next step is securing external integrators.
